# 研究所ステルスゲームの個別進捗

`shadow-route.json` を集計元として、この作品の担当が状態と確認根拠を更新する。総合集計はユーザーが締めで行うため、ここから他作品や総合の数値を変更しない。

- `done`：機能を実装し、記載した範囲の確認が済んだもの。根拠を残す。
- `in_progress`：一部実装済み、調整中、または確認が未完了。
- `todo`：未着手。

完了率は `done件数 ÷ 全件数 × 100`。作業中を部分完了に換算しない。初期計画は2026-10-25時点で58件、完了28・作業中5・未着手25。これはタスク数基準で、工数や品質の完成度ではない。

タスクIDは固定し、既存タスクを毎週細分化して完了数を増やさない。範囲を追加する場合は新しいIDを末尾へ追加し、分母変更を週報へ明記する。週報の作成・再集計自体はゲーム開発タスクとして加算しない。

更新後はリポジトリ内で次を実行する。

```text
python tools/update_shadow_route_progress.py
```

`List` の第3作品のタスク一覧・集計、冒頭と末尾の同作品の進捗を更新する。今週の成果・課題・次週予定は実際の作業記録に沿って別途更新する。根拠の参照先はローカルのゲーム制作フォルダーであり、素材やソース本体はこの報告リポジトリに含めない。
