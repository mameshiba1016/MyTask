# 研究所ステルスゲームの個別進捗

`shadow-route.json` を集計元として、この作品の担当が状態・受入条件・確認根拠を更新する。総合集計はユーザーが締めで行うため、ここから他作品や総合の数値を変更しない。

## 集計基準 第2版（2026-10-25）

他作品のListにあるInput・Player・Camera・Collision・AI・素材・検証などの機能単位を参考に再整理した。全315件、完了219件・作業中13件・未着手83件、69.5％。各項目の完了条件はJSONのacceptance、完了の根拠はevidenceに記録している。

第1版の58件は多数の機能を一項目にまとめ、後工程の分解も不足していたため廃止した。`archive/shadow-route-v1-58.json` に記録のみ残し、現在の件数へ加算しない。今回の完了数の増加は分解と再評価であり、新しい実装が増えた報告ではない。

- done：記載した機能と確認範囲が成立したもの。本番品質・最終実機評価は別タスク。
- in_progress：一部実装済み、調整中、または確認が未完了。
- todo：未着手。

完了率はdone件数÷全件数×100。作業中を部分完了に換算しない。工数やゲーム品質の完成率ではない。親機能とその明細は同時に集計しない。

SR2の固定IDを維持する。今後、完了数を増やすためだけの細分化は行わず、範囲追加は新しいIDと分母変更の理由を記録する。週報作成・集計自体は開発完了数に加算しない。

研究所1ステージを対象とし、複数ステージ・戦闘・オンライン・セーブ／ロードなど採用していない機能を件数稼ぎで追加しない。

更新後は次を実行する。

```text
python tools/update_shadow_route_progress.py
```

Listの第3作品のタスク一覧・分類別集計と、冒頭・末尾の同作品の数値を更新する。今週の成果・課題・次週予定は実際の作業記録に沿って別途更新する。証拠の参照先はローカルのゲーム制作フォルダーで、素材・画像・ソース本体は公開しない。
